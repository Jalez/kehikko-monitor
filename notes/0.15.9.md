- CPU and Memory charts fill in again when Health is opened on a freshly started Monitor, and keep moving after they first draw. Each new sample was added to a history Monitor had already sent, so it never counted as new and the page got no new points.
- What is new is now worked out against a copy of what was sent, and the sampler no longer changes a history it has handed out. Tests run a source that changes its histories in place into the real page, and check that a sample taken earlier is never changed by a later one.
