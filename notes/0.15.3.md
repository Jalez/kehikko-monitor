Kind: feature

- **Your network speed, live.** The Health view has a Network chart beside CPU and Memory: how fast this computer downloads and uploads right now, and over the last five minutes, in one chart with both lines. In a small container it shrinks to a sparkline with both speeds above it.
- **Who is using the link.** With room to spare, the busiest programs are listed under the chart, marked when one is a Kehikot module or an agent session. This needs a Mac.
- **In the footer.** The footer shows both speeds, such as "↓ 2.4 MB/s · ↑ 120 kB/s", whichever view is open.

For agents: the `health` tool has a `network` view. It gives the download and upload speed now, each of the last five minutes' averages and the peak, and on a Mac the busiest programs. Use it to check whether a big download or upload is hogging the link.
