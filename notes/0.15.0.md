Kind: breaking

- **Heavy work outside the queue goes to the Inbox** instead of taking space in Monitor. Each run is one item while it lasts and goes away when it ends. The footer shows how many runs there are.
- **Agents hear about heavy work they start on their own.** When an agent session runs tests, a typecheck or a build outside the module that runs such work in turn, Monitor tells that session once how to hand it over, with the command it ran. It tells only sessions it can name for sure, never your own terminal.
- **Tell agents.** A switch in the Health view's header, on by default. Turn it off to stop these notes. Muting Monitor's messages to agents also stops them.

## For agents

- A `⟦Monitor · report #N⟧` note says you started heavy work outside the work queue here, gives the command, and gives the queue's own command line or tool. Run that work through the queue next time. You get it once per run.
