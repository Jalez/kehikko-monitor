- **See what is calling, live.** A timeline of calls per second by Kehikot and each module, over the last 5, 15 or 60 minutes, with free calls hatched.
- **Find redundant calls.** Repeats lists the same call made again and again, how often, and whether it got the same answer each time.
- **Who calls the most.** A table of each caller's calls a minute, bytes and calls with no reason, and how much of the GitHub budget is used.
- **Every call, with its reason.** Filter the list by caller or words and open a row for its details; connections nobody reported are listed too.
- **Ask an agent.** `/monitor` has an agent tell you what is polling too much.
